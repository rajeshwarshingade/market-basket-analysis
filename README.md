# Market Basket Analysis Using Association Rule Mining

A beginner-friendly college minor project that analyses shopping baskets with the **Apriori** algorithm.
The notebook finds products that are purchased together, measures the rules with **support**, **confidence**,
and **lift**, visualises the results, and explains how a retailer could use them.

## Project summary

Market basket analysis looks for products that appear together in the same transaction. This project uses
the public **Groceries** dataset:

| Item | Value (computed from the data) |
|---|---|
| Transactions | 9,835 |
| Distinct products | 169 |
| Average basket size | 4.41 items |
| Median basket size | 3 items |
| Single-item baskets | 2,159 (22.0%) |
| Minimum support | 1% (an itemset must occur in at least 99 baskets) |
| Minimum confidence | 40% |
| Rules shown (lift > 1) | 62 |

**Main findings**

- **Whole milk** is the most frequent product (2,513 baskets, 25.55%), followed by **other vegetables**
  (1,903; 19.35%), **rolls/buns** (1,809; 18.39%), and **soda** (1,715; 17.44%).
- The strongest rule by lift is `{citrus fruit, root vegetables} -> {other vegetables}` with support
  **1.04%**, confidence **58.62%**, and lift **3.03**.
- Many strong rules are vegetable combinations; dairy items also cluster around whole milk
  (for example, `{curd, yogurt} -> whole milk` has lift **2.28**).
- High-support rules are not always high-lift rules: `yogurt -> whole milk` covers 5.60% of baskets but has
  lift 1.57, while the specialised vegetable rule has lift 3.03 but only 1.04% support.

> These numbers are produced by executing the notebook on the full dataset. They are descriptive patterns,
> not proof that one product causes the purchase of another.

## Dataset

### Source

The **Groceries** dataset is a well-known public basket dataset distributed with the R package `arules`
and mirrored in the *Machine Learning with R* repository:

- **Download URL:**
  <https://raw.githubusercontent.com/stedy/Machine-Learning-with-R-datasets/master/groceries.csv>
- **Expected path:** `data/groceries.csv`
- **Format:** one transaction per line; product names separated by commas
- **Size:** 9,835 transactions, 169 distinct products

### Downloading it again

If `data/groceries.csv` is missing, download it with one of these methods.

**Browser:** open the URL above and save the page as `data/groceries.csv`.

### If the dataset cannot be downloaded

No problem for a demonstration: the notebook detects the missing file, prints a warning, and runs on a
small built-in sample of 40 baskets. In that mode it automatically raises the support threshold to 15%
(because 1% of 40 baskets is less than one transaction) and saves the sample to
`data/sample_baskets.csv`.

The sample is only a backup. **The results in the report come from the full 9,835-transaction dataset.**
If you run the fallback sample, the numbers will be different.

## What the notebook does

1. Loads the raw basket file line by line.
2. Cleans product names: whitespace, lowercase, empty values, missing-like values, duplicate items in a
   basket, and empty baskets.
3. Describes the data: transactions, products, basket sizes, and single-item baskets.
4. Counts product frequencies and draws the **top-products bar chart**.
5. Converts baskets to a **one-hot encoded** table with `TransactionEncoder`.
6. Runs **Apriori** at 1% minimum support and reports frequent itemsets by size.
7. Generates rules at 40% confidence, keeps lift > 1, and ranks them by lift, confidence, and support.
8. Explains support, confidence, and lift with a worked example (`root vegetables -> other vegetables`).
9. Draws a **support vs confidence scatter plot** (colour = lift) and a **top-rules bar chart**.
10. Interprets the rules in plain language and suggests retail actions.
11. Discusses limitations (old data, broad categories, association vs causation, thresholds).
12. Saves all tables and charts to `results/` and `images/`, then runs sanity checks.

### Thresholds used

| Setting | Full dataset | Built-in sample |
|---|---|---|
| `min_support` | 0.01 (1%, at least 99 baskets) | 0.15 (15%, at least 6 baskets) |
| `min_confidence` | 0.40 (40%) | 0.40 (40%) |
| `min_lift` | 1.0 | 1.0 |

These are **choices**, not fixed rules. Lowering support produces more rules, including noisy ones;
raising confidence keeps only more reliable rules. Students can change the constants in the Apriori cell
and observe the effect.

## Limitations (short version)

- The dataset is an older, context-free snapshot: no dates, prices, quantities, customer IDs, or stores.
- Product names are broad categories, not individual SKUs.
- Support thresholds are arbitrary business choices.
- Association rules show co-occurrence, **not causation**.
- The results are not validated on a newer or independent dataset.

See the notebook and report for the full discussion.

## Troubleshooting

**`ModuleNotFoundError: No module named 'pandas'` (or `mlxtend`)**
The notebook is using a different Python kernel. Activate the virtual environment, run
`python -m ipykernel install --user --name mba-venv --display-name "Python (MBA venv)"`, then select
that kernel in Jupyter.

**Charts are not displayed**
Use `%matplotlib inline` (already set by the notebook's import cell) and make sure the kernel is running.

**The notebook says "data/groceries.csv was not found"**
Either download the dataset to `data/groceries.csv`, or accept the built-in sample for a quick demo.
The report numbers apply only to the full dataset.

**Jupyter starts in the wrong folder**
Start Jupyter from the `market-basket-analysis` folder, or move the notebook there before running. The
notebook uses the current working directory to find `data/`, `images/`, and `results/`.
